## 💡 실용적 권장사항

### 1. 최적 설정
```python
# 권장 DataLoader 설정
dataloader = fast_loader.get_dataloader(
    split='train',
    batch_size=512,        # 최적 성능
    shuffle=True,
    num_workers=4,         # CPU 코어 수에 맞게
    pin_memory=True        # GPU 사용 시
)
```

### 2. 전처리 전략
```bash
# 월별 전처리 (권장)
python scripts/pre/preprocess_for_autoencoder.py \
    --db "datasets_norm_all.duckdb" \
    --output-dir preprocessed_2024_10 \
    --start-date 2024-10-01 \
    --end-date 2024-10-31 \
    --max-samples 5000000 \
    --batch-size 10000 \
    --compute-norm-params \
    --create-batches
```

### 3. 점진적 학습 워크플로우
1. **1개월 데이터로 초기 훈련** (8시간 전처리 + 빠른 훈련)
2. **추가 월별 데이터로 점진적 학습** (각 8시간 전처리)
3. **분기별 전체 재훈련** (필요시)
