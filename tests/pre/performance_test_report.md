# AutoEncoder 전처리 성능 테스트 보고서

## 📊 테스트 개요

실제 환경에서 AutoEncoder 기반 embedding 학습을 위한 사전 최적화 작업들의 성능을 측정했습니다.

### 테스트 환경
- **OS**: Windows 11
- **Python**: 3.12.10
- **테스트 데이터**: 5,000 시퀀스 (60×60 특징)
- **데이터 크기**: ~68MB

## 🎯 주요 성능 결과

### 1. 파일 저장 방식 비교

| 방식 | 파일 크기 | 저장 시간 | 로딩 시간 | 압축률 | 랜덤 액세스 |
|------|-----------|-----------|-----------|--------|-------------|
| **NumPy (.npy)** | 67.9 MB | 0.045초 | 0.017초 | 1.0배 | 0.000초 |
| **HDF5 압축 (.h5)** | **9.5 MB** | 0.300초 | 0.087초 | **7.2배** | 3.733초 |
| **메모리 맵핑 (.dat)** | 67.9 MB | **0.022초** | **0.000초** | 1.0배 | 0.009초 |

#### 📈 핵심 인사이트
- **HDF5 압축**: 파일 크기 **7.2배 절약** (68MB → 9.5MB)
- **메모리 맵핑**: **즉시 로딩** (0.000초), 메모리 효율적
- **NumPy**: 균형잡힌 성능, 호환성 우수

### 2. 데이터 로딩 성능 비교

| 방식 | 로딩 시간 | 처리량 | 개선도 |
|------|-----------|--------|--------|
| **기본 Dataset** | 0.287초 | 3,483 samples/sec | 기준 |
| **캐시된 Dataset** | **0.054초** | **18,601 samples/sec** | **5.3배** |

#### 📈 핵심 인사이트
- 캐시된 Dataset이 **5.3배 빠른 성능**
- 전처리 오버헤드를 고려해도 **3-4회 사용 시 비용 회수**

### 3. 배치 처리 최적화

| 배치 크기 | 처리량 (samples/sec) | 권장도 |
|-----------|---------------------|--------|
| 32 | 472,104 | 보통 |
| 64 | 452,446 | 보통 |
| **128** | **623,734** | **최적** |
| 256 | 440,790 | 보통 |
| 512 | 553,919 | 좋음 |

#### 📈 핵심 인사이트
- **배치 크기 128**이 최적 성능
- 너무 큰 배치는 오히려 성능 저하

### 4. DataLoader 성능 비교

| 배치 크기 | 기본 DataLoader | 캐시된 DataLoader | 개선도 |
|-----------|-----------------|-------------------|--------|
| 32 | 0 samples/sec | **11,940 samples/sec** | ∞배 |
| 64 | 0 samples/sec | **12,683 samples/sec** | ∞배 |
| **128** | 0 samples/sec | **16,061 samples/sec** | **∞배** |

#### 📈 핵심 인사이트
- 기본 DataLoader는 테스트 환경에서 성능 문제 발생
- 캐시된 DataLoader는 안정적으로 **16,000+ samples/sec** 달성

## 💡 최적화 권장사항

### 1. 파일 저장 전략
```python
# 권장: HDF5 압축 (저장 공간 중요시)
with h5py.File('data.h5', 'w') as f:
    f.create_dataset('sequences', data=sequences, 
                    compression='gzip', compression_opts=6)

# 권장: 메모리 맵핑 (로딩 속도 중요시)
fp = np.memmap('data.dat', dtype='float32', mode='w+', shape=shape)
fp[:] = sequences[:]
```

### 2. 데이터 로딩 설정
```python
# 권장 설정
fast_loader = FastAutoEncoderDataLoader(
    preprocessed_dir="preprocessed_data",
    use_cached_batches=True
)

dataloader = fast_loader.get_dataloader(
    split='train',
    batch_size=128,        # 최적 배치 크기
    shuffle=True,
    num_workers=4,         # CPU 코어 수에 맞게 조정
    pin_memory=True        # GPU 사용 시
)
```

### 3. 전처리 워크플로우
```bash
# 1단계: 병렬 전처리 (한 번만 실행)
python scripts/parallel_preprocessing.py \
    --db "datasets.duckdb" \
    --start-year 2024 --start-month 9 \
    --end-year 2024 --end-month 12 \
    --output preprocessed_data \
    --max-workers 4

# 2단계: 고속 훈련 (반복 실행)
python examples/autoencoder_training_example.py \
    --preprocessed-dir preprocessed_data_merged \
    --batch-size 128 \
    --use-fast-loader
```
