# Stock-Bot 초 단위 스캘핑 프로젝트 계획서 (plan.md)

## 1. 개요
- 목적: 초 단위 스캘핑 전략을 위한 실시간 AI 트레이딩 시스템 구축
- 범위: 데이터 수집 → 피처 생성 → 모델 학습/검증 → 실시간 추론/주문 → 모니터링까지 End-to-End
- UI: Qt5 기반 데스크톱 클라이언트 (주요 지표/상태, 수동 개입, 전략 온오프)
- 거래 모듈: `koapys` 사용 (주문/계좌/체결/시세 연동)
- 모델: (1) CNN+LSTM+Multi-Head Attention, (2) LightGBM, (3) Transformer
- 대상 마켓: 국내 주식/선물 우선, 확장 가능 구조

## 2. 목표 및 KPI
- 전략 목표: 초 단위 스캘핑으로 수익률 극대화, 회전율 높음, 슬리피지 최소화
- 기술 KPI
  - 예측 지연: 트리거 기준 20ms 이하(모델 추론 5~10ms, I/O 포함 총 20ms 목표)
  - 체결 속도: 주문 전송 후 브로커 ACK < 50ms 목표
  - 가용성: 거래 시간 중 99.9% 이상
  - 리스크 제한: 매수 후 최대 3초내에 상승하지 않으면 손절, 당일 손실 한도, 포지션 한도, 주문 속도 제한 적용
- 모델 KPI
  - 샤프지수(Sharpe) ≥ 1.5, MDD ≤ 5%, 승률/보상비 등 세트별 관리

## 3. 제약 및 가정
- 실시간 피드: 호가/체결 틱 데이터 초 단위 집계 또는 틱 단위 처리
- 인프라: 로컬 Windows 개발 환경 기준, 향후 서버/클라우드 이전 고려
- 종속성: Python 3.10+, PyQt5, numpy/pandas, pytorch/lightgbm, numba, pyarrow, koapys
- 규제/리스크: 실거래 전 사전 모의/페이퍼 트레이딩 의무화

## 4. 시스템 전반 아키텍처 (고수준)
- 데이터 계층
  - 실시간: `koapys` 시세 스트림 → MarketDataBus (in-memory, ZMQ/async queue)
  - 오프라인: Raw(Parquet) → Feature Store(Parquet/Feather) → 모델 입력
- 모델 계층
  - 학습: 백테스트/워크플로우(MLflow/Weights&Biases 선택) 기반 학습/튜닝
  - 추론: 실시간 엔진(저지연) + 모델 버전 관리/롤백
- 전략/리스크/주문 계층
  - 전략: 시그널 → 포지션/주문 생성 → 리스크 필터 → 주문 라우팅
  - 주문: `koapys` 어댑터(재시도, 속도 제한, 예외 처리)
- UI 계층
  - Qt5 대시보드: 포지션/PNL/체결/로그/알람, 전략 온오프, 파라미터 튜닝

## 5. 데이터 및 피처
- 소스: 호가(Order Book), 체결(Tick), 분봉(1s/5s/1m), 공시/뉴스(선택)
- 레이턴시 민감 피처: 스프레드, 호가 잔량 불균형, 마이크로프라이스, 최근 체결 압력, 임펄스, 롤링 VWAP 등
- 레이블: 단기 수익률(예: t+N초의 midprice 변화), 분류(상승/하락/중립) 또는 회귀(수익률)
- 데이터 품질: 시계 동기화(NTP), 결측/이상치 처리, 이벤트 타임 기반 윈도우링

## 6. 모델 라인업
1) CNN+LSTM+Multi-Head Attention (참고: 132649.pdf 유사 구조)
   - 입력: 시계열 창(예: 60×피처), 호가/체결 멀티채널 → CNN 추출 → LSTM → MHA로 컨텍스트 강화
   - 출력: 단기 리턴 확률/값
   - 장점: 지역 패턴+순차 의존성+어텐션으로 급변 포착
2) LightGBM
   - 입력: 집계/통계 피처(라그, 롤링, 차분 등), 카테고리형 최소화
   - 장점: 학습/추론 매우 빠름, 특성 중요도 해석 가능
3) Transformer
   - 입력: 시퀀스 임베딩 + 포지셔널 인코딩, 멀티헤드 어텐션
   - 장점: 장기 의존성, 병렬화, 변동성 급등 구간 대응

## 7. 개발 단계(마일스톤)
- M1: 문서/설계/환경 구성 완료
- M2: 데이터 파이프라인 + 피처 스토어 + 백테스트 스켈레톤
- M3: 베이스라인(룰/간단 모델) + 리스크/주문 라우팅
- M4: LightGBM 파이프라인(학습/검증/추론) 및 실험
- M5: CNN+LSTM+MHA 파이프라인 및 실험
- M6: Transformer 파이프라인 및 실험
- M7: 실시간 추론 + 모니터링 + UI 통합
- M8: 모의/페이퍼 → 제한적 실거래 A/B → 점진적 확대

## 8. 일정(초안)
- 주 단위 8~12주 계획, 각 마일스톤별 데모/리뷰

- 드리프트: 데이터/성능 드리프트 감지, 자동 알람 및 롤백
- 장애/예외: 네트워크/브로커 오류 대비 재시도/폴백, 냉온 스타트 처리
- 규율: 손절/익절/일손실한도, 주문 레이트 한도, 비상 스위치
