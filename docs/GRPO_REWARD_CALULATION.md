# GRPO 보상 계산 로직 구현 문서

## 개요

이 문서는 GRPO 스캘핑 환경의 보상 계산 로직 구현을 설명합니다.

## 요구사항

### 요구사항 3.2: 보상 계산
- 거래 비용 계산 (수수료 0.015% + 세금 0.2% = 0.215%, 왕복 0.43%)
- 수익률 기반 보상: (청산가 - 진입가) / 진입가 - 거래비용
- 양의 보상 조건: 수익률 > 0.43%
- 장기 보유 페널티: -0.001 * (보유시간 - 60초)

## 구현 세부사항

### 1. 거래 비용 계산

```python
# 단방향 거래 비용: 0.215%
transaction_cost_rate = 0.00215

# 왕복 거래 비용: 0.43%
round_trip_cost = transaction_cost_rate * 2  # 0.0043
```

**구성:**
- 수수료: 0.015%
- 세금: 0.2%
- 합계: 0.215% (매수/매도 각각)
- 왕복: 0.43% (매수 + 매도)

### 2. 수익률 기반 보상

```python
# 수익률 계산
profit_rate = (exit_price - entry_price) / entry_price

# 거래 비용 차감
reward = profit_rate - round_trip_cost
```

**예시:**
- 진입가: 100원
- 청산가: 101원
- 수익률: (101 - 100) / 100 = 0.01 (1%)
- 보상: 0.01 - 0.0043 = 0.0057 (0.57%)

### 3. 양의 보상 조건

양의 보상을 받으려면 수익률이 거래 비용(0.43%)을 초과해야 합니다.

**경계값 테스트:**
- 수익률 0.43%: 보상 = 0.0043 - 0.0043 = 0.0
- 수익률 0.5%: 보상 = 0.005 - 0.0043 = 0.0007 (양의 보상)
- 수익률 0.3%: 보상 = 0.003 - 0.0043 = -0.0013 (음의 보상)

### 4. 장기 보유 페널티

60초를 초과하여 포지션을 보유하면 페널티가 적용됩니다.

```python
if holding_time > max_holding_time:  # 60초
    penalty = holding_penalty_rate * (holding_time - max_holding_time)
    reward -= penalty
```

**예시:**
- 보유 시간 60초: 페널티 없음
- 보유 시간 70초: 페널티 = 0.001 * (70 - 60) = 0.01
- 보유 시간 100초: 페널티 = 0.001 * (100 - 60) = 0.04

### 5. 보상 구성 요소

`_calculate_reward` 메서드는 다음 구성 요소를 반환합니다:

```python
reward_components = {
    'profit_rate': float,        # 수익률
    'transaction_cost': float,   # 거래 비용 (음수)
    'holding_penalty': float,    # 보유 페널티 (음수)
    'net_reward': float          # 최종 보상
}
```
