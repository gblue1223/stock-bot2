# 실시간 프로그램 매매 10분할 자동매매 모듈 (`algo_trader/program`)

키움 REST API를 연동하여 실시간/장중 **프로그램 매매 수급 동향**을 모니터링하고, 프로그램 순매수 유입 시 **10분할 분할 매수/매도**를 자동으로 집행하는 알고리즘 트레이딩 모듈입니다.

---

## 🌟 주요 특징

1. **실시간 프로그램 수급 추적**:
   - `MarketCondition.stockwise_program_trading_by_hour_request_ka90008` 및 `StockInfo` API를 사용하여 장 중 프로그램 순매수 금액 및 증감 추이를 실시간 모니터링합니다.
2. **10분할 분할 주문 엔진 (Split Execution Engine)**:
   - 한 번에 전량 매수하지 않고, 프로그램 순매수 유입 시 종목당 설정한 총 예산을 **10회로 나누어 5분(또는 지정된 주기) 간격으로 분할 집행**합니다.
3. **리스크 및 잔고 자동 관리**:
   - **손절 (-2.0%)** / **익절 (+3.0%)** 도달 시 보유 수량 전량 시장가 매도 및 당일 매매 자동 중단.
   - **장 마감 전(기본 15:15:00)** 미청산 포지션 일괄 자동 시장가 청산.
4. **안전한 모의 실행 (Dry-Run)** 지원:
   - `--dry-run` 옵션을 통해 실제 주문 송신 없이 수급 분석 및 10분할 트레이딩 로직을 모의 테스트 가능.

## 🚀 사용법 및 실행 명령

### 1. 드라이런 (모의 트레이딩) 실행
실제 주문을 내지 않고 수급 감시 및 10분할 로직을 테스트합니다.
```bash
.venv64/Scripts/python -m algo_trader.program.main --stocks "005930,000660" --dry-run
```

### 2. 실전 자동 매매 실행
종목당 2,000,000원 예산으로 삼성전자(005930)와 SK하이닉스(000660) 10분할 매매를 실행합니다.
```bash
.venv64/Scripts/python -m algo_trader.program.main --stocks "005930,000660" --budget 2000000 --splits 10
```

### 3. 상세 옵션
```text
--stocks, -s     : 대상 종목코드 목록 (예: "005930,000660")
--budget, -b     : 종목당 총 투자 예산 (원, 기본값: 1,000,000원)
--splits, -n     : 분할 매매 횟수 (기본값: 10)
--interval, -i   : 분할 매수 실행 최소 간격 (초 단위, 기본값: 300초 = 5분)
--stop-loss      : 손절 비율 (%, 기본값: 2.0)
--take-profit    : 익절 비율 (%, 기본값: 3.0)
--close-time     : 장 마감 전 자동 청산 시각 (기본값: 15:15:00)
--account, -a    : 계좌번호 지정 (선택사항)
--dry-run        : 모의 실행 모드
```
