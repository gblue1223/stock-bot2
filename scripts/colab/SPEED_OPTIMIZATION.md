# 학습 속도 최적화 가이드

## 🚀 A100 80GB 최적화 설정

### 최적화된 설정
```python
MAX_SAMPLES = 30000000   # 3천만 (월별 전체 데이터)
BATCH_SIZE = 4096        # A100 80GB 최적
INITIAL_EPOCHS = 15
NUM_WORKERS = 16
VAL_EVERY = 2
```

### 예상 성능
```
배치당 시간: ~2분 (120초)
총 배치: 5,208 (3천만 / 4096)
1 에포크: 174시간 (7.3일)
15 에포크: 2,610시간 (109일)
Early Stopping: 약 60-70일 ✅
```

## 🚀 즉시 적용 (권장)

### 1. **샘플 수 감소** ⭐⭐⭐⭐⭐

```python
# 이전
MAX_SAMPLES = 10000000  # 1천만
Train batches: 13,659
1 epoch: 295시간

# 이후
MAX_SAMPLES = 5000000   # 500만
Train batches: 6,830
1 epoch: 148시간 (50% 감소!)
```

**효과**: 
- 속도 **2배** 향상
- 메모리 사용량 **50%** 감소
- 여전히 충분한 데이터 (3천만의 16.7%)

---

### 2. **에포크 감소** ⭐⭐⭐⭐

```python
# 이전
INITIAL_EPOCHS = 20
총 시간: 295시간 × 20 = 5,900시간 (246일)

# 이후
INITIAL_EPOCHS = 10
총 시간: 148시간 × 10 = 1,480시간 (62일)
```

**효과**:
- 총 훈련 시간 **50%** 감소
- Early Stopping으로 실제로는 5-7 에포크면 충분

---

### 3. **검증 주기 증가** ⭐⭐

```python
# 이전
VAL_EVERY = 1  # 매 에포크마다 검증

# 이후
VAL_EVERY = 2  # 2 에포크마다 검증
```

**효과**:
- 검증 시간 **50%** 절약
- 검증은 시간이 오래 걸림 (2,927 배치)

---

## 🔧 추가 최적화 (선택)

### 4. **배치 크기 증가** ⭐⭐⭐

```python
# V100 (16GB)
BATCH_SIZE = 512  # 현재

# A100 (40GB) 또는 메모리 충분 시
BATCH_SIZE = 1024  # 2배 증가
```

**효과**:
- 배치 수 **50%** 감소
- GPU 활용도 향상
- **주의**: 메모리 부족 가능

**테스트 방법**:
```python
# 노트북에서 시도
BATCH_SIZE = 768  # 먼저 768로 테스트
# 성공하면
BATCH_SIZE = 1024
```

---

### 5. **NUM_WORKERS 증가** ⭐⭐

```python
# 이전
NUM_WORKERS = 4

# 이후
NUM_WORKERS = 8  # CPU 코어 수에 따라
```

**효과**:
- 데이터 로딩 속도 향상
- GPU 대기 시간 감소

---

### 6. **시퀀스 길이 감소** ⭐⭐

```python
# 이전
SEQ_LEN = 60  # 60 timesteps

# 이후
SEQ_LEN = 30  # 30 timesteps
```

**효과**:
- 계산량 **50%** 감소
- 메모리 사용량 감소
- **주의**: 시간적 패턴 학습 능력 감소
