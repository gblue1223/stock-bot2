# A100 80GB 최적화 가이드

## 🚀 최적화된 설정

### 핵심 설정
```python
MAX_SAMPLES = 30000000   # 3천만 샘플 (월별 전체 데이터)
BATCH_SIZE = 4096        # A100 80GB 최적 배치 크기
INITIAL_EPOCHS = 15      # 대용량 데이터에 맞게 증가
NUM_WORKERS = 16         # 데이터 로딩 가속
VAL_EVERY = 2            # 2 에포크마다 검증
CHECKPOINT_INTERVAL = 3  # 3 에포크마다 저장
```

## 🎯 최적화 포인트

### 1. **대용량 배치 (4096)** ⭐⭐⭐⭐⭐

**장점**:
- GPU 활용도 최대화
- 배치 수 대폭 감소 (62%)
- Gradient 안정성 향상

**메모리 사용**:
```
모델: ~2GB
배치 데이터: 4096 × 60 × 28 × 4 bytes = ~27GB
Gradient: ~2GB
여유: ~49GB ✅
```

---

### 2. **전체 데이터 사용 (3천만)** ⭐⭐⭐⭐⭐

**효과**:
- 과적합 방지
- 더 나은 일반화
- 다양한 패턴 학습

**메모리 사용**:
```
데이터: 30M × 28 × 4 bytes = ~3.4GB
메타데이터: 30M × 3 × 8 bytes = ~0.7GB
총: ~4.1GB (RAM) ✅
```

---

### 3. **많은 워커 (16)** ⭐⭐⭐⭐

**효과**:
- 데이터 로딩 병렬화
- GPU 대기 시간 최소화
- CPU 활용도 향상

**권장**:
```python
NUM_WORKERS = 16  # A100 환경 최적
```

---

### 4. **검증 주기 조정 (2)** ⭐⭐⭐

**효과**:
- 검증 시간 50% 절약
- 훈련 속도 향상

**검증 시간**:
```
Val 배치: 879 (4.5M / 4096 / 1.25)
검증 시간: ~30분
절약: 15분/에포크
```

## 💡 추가 최적화 옵션

### 옵션 1: 더 큰 배치 (8192)

```python
BATCH_SIZE = 8192  # 메모리 충분 시
```

**효과**:
- 배치 수: 5,208 → 2,604 (50% 감소)
- 1 에포크: 174시간 → 104시간 (40% 빠름!)

**메모리**:
```
배치 데이터: 8192 × 60 × 28 × 4 = ~54GB
총 사용: ~58GB
여유: ~22GB ✅ 가능!
```

---

### 옵션 2: 학습률 증가

```python
# 큰 배치 크기에 맞춰 학습률 증가
INITIAL_LR = 1e-4  # 5e-5 → 1e-4 (2배)

# Linear Scaling Rule
# LR = base_lr × (batch_size / base_batch_size)
# 1e-4 × (4096 / 512) = 8e-4
```

**주의**: 점진적으로 증가하며 테스트

---

### 옵션 3: Gradient Accumulation (메모리 부족 시)

```python
# 메모리 부족하면
BATCH_SIZE = 2048
ACCUMULATION_STEPS = 2  # 효과적 배치: 4096
```

### GPU 메모리 확인

**기준**:

- **70-75GB**: 적정 → BATCH_SIZE = 4096 유지

### RAM 메모리 확인
```python

print(f"RAM: {psutil.virtual_memory().percent}%")
```

**기준**:
- **< 80%**: 안전
- **> 90%**: NUM_WORKERS 감소 (16 → 8)
