## 📈 기대 성과

### 보수적 시나리오

```
Win Rate: 70%
Avg Profit: 5%
Avg Loss: -2%
Trades per Day: 10

Expected Daily Return: 
= (0.7 × 5%) + (0.3 × -2%)
= 3.5% - 0.6%
= 2.9%

Monthly Return (20 trading days):
= 2.9% × 20
= 58%  (복리 고려 시 더 높음)
```

### 현실적 시나리오 (슬리피지 고려)

```

Avg Profit: 4%  (슬리피지 -1%)
Avg Loss: -2.5%  (슬리피지 -0.5%)
Trades per Day: 8  (체결 실패 고려)

Expected Daily Return:
= (0.7 × 4%) + (0.3 × -2.5%)
= 2.8% - 0.75%
= 2.05%

Monthly Return:
= 2.05% × 20
= 41%
```
